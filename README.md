Precise Painter is a Minecraft mod that allows you to select the painting that you want to place. Whenever you place a painting, the block will be put down with a random painting selection like normal. Then, it will open a menu and allow you to choose what painting you would like to place and the painting will adjust. You can crouch while placing a painting if you need to bypass this menu for any reason.

![Client and Server Example](https://cdn.modrinth.com/data/cached_images/06326e4ec3941824bcb3dd2dce7150a41a877649.png)

If you have the mod installed on the client and the server, then you will see the paintings in the menu and be able to choose exactly which one you want.

![Server Example](https://cdn.modrinth.com/data/cached_images/e9a1d8c32f3da590a38bb7a39cc26ef530a878c6.png)

If the mod is only installed on the server, you will not see the rendered paintings, but the mod is still completely functional.
